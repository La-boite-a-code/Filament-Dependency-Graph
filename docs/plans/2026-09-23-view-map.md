# View Map Implementation Plan

**Spec:** `docs/specs/2026-09-23-view-map-design.md`. Same global constraints as the HTTP map plan.

1. Domain: node and edge types, `GraphScope::Views`, DTOs under `Domain/DTO/Views`, identifiers, `ApplicationSnapshot::$views`, `ControllerActionData::$views`, `SchemaVersion` 1.4.
2. Configuration, `DiscoveryContext`, plugin `allowViewsScope()`, fixtures (`tests/Fixtures/views`, components, Filament classes, mail).
3. `MethodSource::viewLiterals()` and controller action views.
4. `BladeTemplateScanner`.
5. `LivewireAdapter` (v3 registry, v4 finder) and `ViewReferenceResolver`.
6. `ViewOwnerDiscoverer`, `ViewMapDiscoverer`, orchestration and warnings.
7. Graph assembly, Views scope, HTTP bridge, badges.
8. Inspectors, page (scope, datasets, tree), translations.
9. Renderer styles, Mermaid labels, CLI scope, asset build.
10. ADR 0011, README, CHANGELOG, independent review, fixes, release v1.2.0.
